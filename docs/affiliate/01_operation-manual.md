# 運用マニュアル（投稿手順・チェックリスト・ログ）

## 1. 投稿の型

Threadsは「本文」と「リプライ」の2段構成で使う。リンクは**必ずリプライ側**に置く。
（本文に外部リンクを入れると露出が落ちる、というのがこのスキームの前提）

```
┌─ 本文（メイン投稿）────────────────────┐
│ <フック1行>                            │
│                                        │
│ <本文 120〜200字>                      │
│                                        │
│ #PR                                    │
└────────────────────────────────────────┘
          ↓「スレッドに追加」
┌─ リプライ ─────────────────────────────┐
│ <誘導文 一言>                          │
│ <Amazonアフィリエイトリンク>           │
│ #PR                                    │
└────────────────────────────────────────┘
```

### リンクの作り方
Amazonアソシエイトのツールバー →「リンクを作成」→ ショートリンクにチェック →
「アフィリエイトリンクをコピー」

> ⚠ 動画では触れられていないが、**リンクの短縮・改変は運営規約で制限がある**。
> Amazon公式が発行するショートリンク（amzn.to）以外の短縮サービスは使わないこと。

---

## 2. 投稿前チェックリスト（毎回・例外なし）

- [ ] **①架空の体験談が混ざっていないか**（自分が使っていない商品を「使った」と書いていないか）
- [ ] **②薬機法NG語が入っていないか**（治る・効く・改善する・消える・痩せる 等）
- [ ] **③根拠のない最上級表現がないか**（最安・No.1・絶対・必ず・100%）
- [ ] **④本文とリプライの両方に `#PR` があるか**
- [ ] **⑤リンクが自分のトラッキングIDになっているか**（コピペミスの定番）
- [ ] **⑥価格を断定していないか**（「2,980円」ではなく「2,000円台」）
- [ ] **⑦同じ商品リンクを短期間に連投していないか**（スパム判定回避）

## 3. 薬機法NGワード（生成物に対する機械チェック用）

以下は投稿文に**含まれてはいけない**語。プロンプトにも埋め込み済みだが、
最終確認は人間の目で行う。

### 治療・治癒を示す語
治る / 治す / 治療 / 完治 / 改善する / 効く / 効果がある / 症状が消える / 緩和する

### 身体の変化を断定する語
シミが消える / シワがなくなる / ニキビが治る / 痩せる / 脂肪が落ちる / 若返る /
発毛する / 血圧が下がる / 血糖値が下がる / 免疫力が上がる / デトックス

### 医薬品的な作用を示す語
予防する / 殺菌する / 抗菌する（承認された効能表示を除く）/ 炎症を抑える

### 景表法で危険な語
最安 / 業界No.1 / 日本一 / 絶対 / 必ず / 100% / 誰でも / 確実に

> 食品・野菜ジャンルでも「免疫力が上がる」「がん予防」等の健康効果表現はNG。
> 味・食感・調理性・保存性・価格・容量の記述にとどめる。

- 表示数・いいね・返信 → Threadsのインサイト
- リンククリック・注文・紹介料 → Amazonアソシエイトのレポート（トラッキングID別）

### トラッキングIDの使い分け（重要）
投稿の切り口ごとにトラッキングIDを分けておくと、**どの型が売れたか**が分かる。
Amazonアソシエイト管理画面で複数IDを発行できる。

| 時短・手軽さ重視 | |
| 共感重視 | |

## 5. 週次レビュー（毎週1回・15分）

1. 表示数トップ3の投稿の**1行目だけ**を抜き出す
2. 共通点を1文で言語化する（例：「否定形で始めると伸びる」）
3. その知見をプロンプトの「執筆ルール」に1行追記する

これを回すと、プロンプトが自分専用に育っていく。配布プロンプトを使い続けるより強くなる。
