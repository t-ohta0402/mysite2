# 商品選定ルールと候補リスト

## 1. 選定ルール

ネタ切れで止まるのが最大の失敗要因なので、**投稿を始める前に30件確保する**。

### 選ぶ基準
- [ ] Amazonでレビュー件数が多い（＝すでに売れている証明がある）
- [ ] 単価が1,500円以上（低単価すぎると紹介料が残らない）
- [ ] 自分が実際に使っている、または実務で知見がある
- [ ] 説明に薬機法の壁がない（＝化粧品・サプリ・健康食品を避ける）
- [ ] 季節性がある、または繰り返し買われる（リピート商材）

### 避けるもの
- 化粧品・医薬部外品・サプリ（薬機法）
- 家電の高額品（Amazonは高額品ほど料率上限がかかる場合がある。要確認）
- レビューが極端に少ない新商品
